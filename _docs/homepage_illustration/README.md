# Homepage illustration exploration

Hand-built SVG illustrations of the Hartge "Quadrant" sloop (hull #9, "Oyster"),
explored as candidate homepage art. Not served by GitHub Pages.

- `gallery.html` — comparison page (open directly in a browser). Currently leads
  with **Chesapeake Watercolor** as the selected direction; four alternate
  directions are kept below for reference.
- `svg/` — the individual illustrations, one file per direction.

Reference photo: "Oyster," Hartge Quadrant sloop hull #9, built 1956 at Hartge
Yacht Yard (Galesville, MD); photographed for a 2024 listing at
offcenterharbor.com. See `../logos.v1/pics_quadrant_web/SOURCES.md` for the
source photos these were drawn from.
