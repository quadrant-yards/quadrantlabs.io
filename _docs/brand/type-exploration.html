Three type pairings in Clear Day

The "QUADRANT" wordmark stays in Jost in every pairing. What changes is the font for headings, body text, interface text and code. Each pairing is shown on the website, a long article, an app screen with numbers, and code.

All three avoid the AI-default pairing: a soft, high-contrast display serif (Fraunces, Instrument Serif, Playfair) over Inter in grey. Inter is also out, because it's on nearly every AI-generated page.

T1Engineered

Jost for headings, so headings and the wordmark come from the same family. IBM Plex Sans for everything else, with its matching Plex Mono for code. Plex was designed for engineering work: it has slightly squared curves and reads as precise without being cold.

Feels: precise, technical, calm, and unified with the logo · Strength: one font for all interface text keeps rules simple for agents; Plex's sans and mono were designed together · Risk: the safest of the three and the least memorable on its own

T2Hull Lettering

Archivo, a sturdy grotesque, set wide and bold for headings, like a boat's name and hailing port lettered on the transom. The same family at normal width does body and interface text, with JetBrains Mono for code. Jost appears only in the wordmark, which then stands apart from everything around it.

Feels: sturdy, workmanlike, confident · Strength: the most distinctive headings; one family for nearly everything · Risk: wide bold headings are loud; they need short headlines, and long titles wrap awkwardly

T3Logbook

Jost for headings, a sturdy reading serif (Source Serif 4) for long text such as essays and case studies, and Source Sans 3 for interface text. Source Code Pro for code. It's like a ship's log: clean printed headings over handwritten-feeling entries. It suits writing-heavy work like guides and engineering memos.

Feels: thoughtful, literary, considered · Strength: best for long reading, and the serif is a working text face, not a soft display serif · Risk: four fonts to manage; agents need a clear rule for when serif applies (long-form only, never in app UI)

What to look for

  • The article block shows whether you'd want to read a whole case study in it.
  • The app table shows whether numbers line up and labels stay readable at small sizes.
  • The code block shows whether 0O, 1lI and {} are easy to tell apart.
  • The wordmark next to the headings shows whether they feel like one family (T1, T3) or a deliberate contrast (T2).

Mixing is fine, e.g. T1 with T3's serif only for essays. All fonts are free on Google Fonts.
