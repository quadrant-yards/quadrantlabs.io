Quadrant Agents

Privacy policy

Effective Nov 1, 2026

This policy covers Quadrant Agents, a private assistant tool for one household user.

Who operates it

Quadrant Agents is operated by Quadrant Labs. Contact: sam@quadrantlabs.io

Google data it accesses

  • Gmail messages, read-only
  • Google Calendar events, view and edit
  • The user's list of calendars, read-only
  • Basic account info: the user's email address

Why it uses this data

To let the user's personal assistant read their email and manage their calendar events when the user asks. The data is not used for anything else.

Sharing

Google user data is not sold, not used for advertising, and not shared with third parties except as needed to provide the feature. To answer a request, the relevant email or calendar content is sent to an AI model provider, only for that request.

Storage and retention

Email and calendar content is not kept after the assistant uses it. It is processed to answer the user's request and then discarded.

The only thing stored is the OAuth access token, which is encrypted on a private server and kept until the user revokes access.

Revoking access

The user can revoke access at any time at myaccount.google.com/permissions. Revoking access stops Quadrant Agents from reading or changing any Google data.

Google API Services User Data Policy

Quadrant Labs' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Changes to this policy will be posted on this page with a new effective date.
